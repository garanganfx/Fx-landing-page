Quick Start Guide

4 Langkah Mudah Menjalankan Robot

Proses setup instan kurang dari 15 menit. Tim support kami siap mendampingi via remote assistance.

01

Buka Akun Broker Rekomendasi

Gunakan broker ECN / Raw Spread dengan leverage minimal 1:100 agar slippage mendekati nol saat eksekusi posisi.

02

Sewa Cloud VPS Forex

Gunakan VPS berlokasi di London / New York dengan latensi ping < 5ms ke server broker agar eksekusi instan 24 jam.

03

Instal File EA & Load Preset

Copy file (.ex4 / .ex5) ke folder Experts MT4/MT5. Muat file .set teruji kami sesuai profil risiko (Konservatif / Prop-Firm).

04

Aktifkan "AutoTrading"

Klik tombol AutoTrading hingga ikon wajah tersenyum. Biarkan algoritma mengidentifikasi peluang profit secara otomatis.
